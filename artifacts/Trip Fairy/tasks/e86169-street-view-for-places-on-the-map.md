## Brief
Let users see street-level imagery for a stop or place. Options: link out to Google Maps Street View (a documented map URL with the location; no API key, opens in a new tab); embed Mapillary (free, open imagery; needs a token and CC BY-SA attribution); or Google Street View embed (needs a paid API key and billing). Start with the link-out from map popups and place cards, then consider an embed.
